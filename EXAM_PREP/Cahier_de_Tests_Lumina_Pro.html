Cahier de Tests Fonctionnels — Lumina Pro

Application Kanban collaborative — API REST (Node.js/Express) + interface web

Date d'exécution : 07/07/2026 Environnement : Local (XAMPP MySQL + node server.js) Méthode : Requêtes HTTP directes (curl) sur l'API, données remises à zéro via seed.js
Résultats :
Réussis : 15
Échoués : 0
Méthodologie : ces 12 tests ont été exécutés réellement contre le serveur Lumina Pro lancé en local (MySQL via XAMPP + node server.js), en appelant directement les routes de l'API REST. La base a ensuite été remise dans son état de démonstration via node seed.js. Les identifiants de démo utilisés (admin@lumina.com / Lumina1!) correspondent à ceux documentés dans le README, désormais alignés avec ce que seed.js insère réellement (voir correctif appliqué au script).
