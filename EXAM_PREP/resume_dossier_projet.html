Contexte du projet
Type :Projet solo — formation DWWM
Objectif :Outil de gestion de tâches en équipe
Cible :Petites équipes (PME, startups)
Concurrent :Alternative légère à Trello / Jira
GitHub :github.com/syrinedev-06/LUMINA_PRO
Stack technique
HTML5 CSS3 Modulaire JavaScript ES6+ Fetch API Node.js Express 5 REST API MySQL 8 XAMPP JWT bcrypt Swagger UI
Architecture :MVC — frontend Vanilla JS / backend Node.js
Fonctionnalités livrées
  • Authentification JWT (login / inscription)
  • Tableau Kanban dynamique (colonnes personnalisables)
  • CRUD complet tâches et colonnes
  • Déplacement des tâches (boutons ⬅️ ➡️)
  • Tri automatique par priorité (URGENT en haut)
  • Assignation de tâches aux membres
  • Gestion des rôles admin / utilisateur
  • Interface responsive (mobile et desktop)
  • Documentation API Swagger
  • Logs d'audit de toutes les actions
3 Missions réalisées
Mission 1
Authentification & Gestion des rôles
bcrypt, JWT, verifyToken, localStorage, rôles admin/user
Mission 2
Tableau Kanban — CRUD tâches et colonnes
renderBoard, filter/map/join, FIELD() priorité, PUT dynamique
Mission 3
API REST sécurisée & Documentation
12 endpoints, Swagger, authFetch() DRY, escapeHTML() XSS
Base de données
SGBD :MySQL 8 — InnoDB (ACID)
Tables :users · columns · tasks · logs
Relations :FK tasks→columns (CASCADE), tasks→users (SET NULL)
Tri SQL :FIELD(priority, 'high','medium','low') ASC
Jointure :LEFT JOIN users → conserve tâches non assignées
Sécurité
🔐JWT — token signé HS256, expiration 24h, header Authorization
🔑bcrypt — hachage irréversible, sel aléatoire, 10 rounds
🛡️XSS — escapeHTML() sur tout le contenu utilisateur affiché
💉SQL Injection — requêtes préparées avec placeholders ?
🚫CSRF — JWT dans header (pas cookie), non injectable cross-site
