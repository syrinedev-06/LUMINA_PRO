1. Modifications du code source

Ces fichiers ont été modifiés directement dans ton projet Lumina Pro.

🗑️
Suppression du toggle Dark/Light sur la page connexion code
frontend/login.html
Supprimé : le <script> qui chargeait le dark mode au démarrage, le bouton LIGHT/DARK avec le switch animé, la fonction toggleTheme() et son window.addEventListener.
Pourquoi : tu as demandé de le retirer de la page connexion.
📊
Tri des tâches par priorité dans chaque colonne code
backend/routes/tasks.js
Modifié la requête SQL du GET /api/tasks :
Avant : ORDER BY id_col ASC, created_at DESC
Après : ORDER BY id_col ASC, FIELD(tasks.priority, 'high', 'medium', 'low') ASC, created_at DESC
Résultat : dans chaque colonne, les tâches URGENT apparaissent en haut, NORMAL en bas.
Pourquoi : FIELD() retourne la position dans la liste → high=1, medium=2, low=3 → tri croissant met les urgentes en premier.

7. Points importants à retenir pour l'oral

💡
Drag & Drop : ne pas le mentionner
Le code source ne contient pas de drag & drop HTML5 (pas de draggable, dragstart, dragover, drop). Le déplacement des tâches se fait via les boutons ⬅️ ➡️ qui appellent moveTask(). Si le jury te demande : "Je déplace les tâches avec des boutons directionnels qui envoient un PUT au serveur avec le nouvel id_col."
💡
Classement des tâches par priorité
Les tâches sont maintenant triées : URGENT en haut, NORMAL en bas dans chaque colonne.
Requête SQL : ORDER BY FIELD(tasks.priority, 'high', 'medium', 'low') ASC
FIELD() retourne l'index de la valeur dans la liste : high→1, medium→2, low→3. Tri ASC = 1 avant 2 avant 3.
💡
Fichier .env : comment l'expliquer au jury
"En production, je mettrais la clé secrète JWT dans un fichier .env qui est listé dans .gitignore, donc jamais envoyé sur GitHub. Le code lirait process.env.SECRET_KEY. Pour ce projet de certification, la clé est dans le code source pour faciliter l'installation, mais c'est une limite que je saurais corriger."
