Lumina Pro est un tableau Kanban de gestion de tâches — un espace de travail unique pour remplacer les post-its, les tableurs et les fils de messages qui s'accumulent. L'idée est simple : des colonnes que l'on personnalise, des cartes que l'on déplace au fil de leur avancement, des priorités visibles d'un coup d'œil. Chaque écran a été pensé pour être clair et direct, sans superflu.

Le projet couvre toute la chaîne d'une application web : une base de données pour stocker les informations, un serveur qui gère la logique et les accès, et des pages web que l'utilisateur voit et manipule. La connexion est sécurisée, les comptes sont protégés. Tout a été construit sans bibliothèque toute faite, pour maîtriser chaque partie du code et être capable de l'expliquer.

Le périmètre a été volontairement resserré autour d'un cœur solide : les fonctionnalités essentielles, bien réalisées, plutôt qu'un projet trop large mal maîtrisé.

Lumina Pro n'est pas une tentative de copier Trello ou Jira. C'est un projet de certification qui démontre, de la base de données à l'interface, qu'il est possible de construire une application complète et sécurisée — avec une exigence simple : être capable d'expliquer chaque choix.
