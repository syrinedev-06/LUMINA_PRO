Dépendances entre packages
SourceCibleType de dépendanceExplication
frontend ──uses──▶ backend / API «use» Le front envoie des requêtes HTTP (fetch) vers les routes Express
backend / routes ──uses──▶ database «use» Chaque route exécute des requêtes SQL via le pool MySQL (config/db.js)
backend / routes ──uses──▶ sécurité «import» Les routes importent verifyToken, bcrypt, jwt depuis les modules sécurité
frontend / api.js ──uses──▶ sécurité «use» authFetch() lit le token JWT depuis localStorage et escapeHTML() sanitise les données
backend ──serves──▶ frontend «deploy» express.static() sert les fichiers HTML/CSS/JS du dossier frontend
documentation ──describes──▶ backend / API «document» swagger.json décrit toutes les routes de l'API, affiché par swagger-ui-express
Note de conception : Il n'y a pas de couche Model/Controller séparée — les routes contiennent directement leurs requêtes SQL. C'est un choix délibéré adapté à la taille du projet (solo, 4 tables), documenté comme piste d'amélioration dans la roadmap.
