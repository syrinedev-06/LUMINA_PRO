🎯 Diagramme de Cas d'Utilisation — Lumina Pro

Diagramme Use Cases UML — Système Lumina Pro

Lecture : Les ellipses représentent les cas d'utilisation. Les acteurs interagissent avec le système via des associations (traits pleins). Le rôle Admin hérite de tous les droits de l'Utilisateur (flèche de généralisation ▷) et dispose en plus des actions d'administration.

Contrôle d'accès : Côté serveur, le middleware verifyToken vérifie le JWT à chaque requête. La vérification du rôle (req.user.role === 'admin') est effectuée dans les routes de gestion d'équipe et de colonnes pour empêcher un utilisateur simple d'accéder aux fonctions d'administration.
